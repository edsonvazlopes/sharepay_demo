# Branding

Esta pasta é reservada para materiais públicos de identidade visual do SharePay, como logotipo, ícones ou imagens institucionais previamente autorizadas.

Antes de adicionar arquivos aqui, confirme:

- O material pode ser publicado em repositório público.
- Não há marcas de terceiros usadas sem autorização.
- A imagem não contém dados pessoais, valores financeiros ou conteúdo privado.
- O arquivo possui nome descritivo.
