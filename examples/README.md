# Examples

Os arquivos desta pasta são exemplos ilustrativos, simplificados e independentes.

Eles não representam o código de produção do SharePay, não documentam a implementação real e não devem ser usados para inferir regras internas de negócio, autenticação, autorização, banco de dados, billing ou infraestrutura.

- `validation-example.ts`: validação simples sem dependências externas.
- `service-contract-example.ts`: contratos genéricos entre domínio e persistência.
- `component-example.tsx`: componente React tipado e acessível.
