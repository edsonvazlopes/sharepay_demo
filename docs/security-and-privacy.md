# Security And Privacy

Este documento descreve apenas princípios públicos de segurança e privacidade. Ele não documenta mecanismos internos, regras reais de autorização, endpoints, infraestrutura ou detalhes que possam facilitar ataques.

## Princípios públicos

- Segredos fora do repositório.
- Controle de acesso por usuário e carteira.
- Validação de dados relacionados a valores, datas, participantes e estados.
- Proteção de informações financeiras e pessoais.
- Logs sem dados sensíveis.
- Separação de ambientes.
- Atualização responsável de dependências.
- Divulgação responsável via [SECURITY.md](../SECURITY.md).
