## Imagens que exigem revisão manual

Todas as imagens desta pasta exigem revisão manual antes de uso público.

A inspeção automatizada limitada indicou que alguns screenshots podem conter informações visíveis que devem ser tratadas com cuidado, como e-mails, nomes de usuário, nomes de teste e valores financeiros. Por esse motivo, nenhuma imagem foi incluída diretamente no `README.md`.

Durante a revisão, verificar se há dados pessoais, e-mails, telefones, documentos, valores financeiros reais, dados de carteira, membros ou lançamentos reais, tokens, chaves, IPs, portas, rotas administrativas, endpoints internos, mensagens de erro reais ou logs.
