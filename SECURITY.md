# Security Policy

Este repositório não contém o código-fonte de produção do SharePay.

Não abra vulnerabilidades do sistema real como issue pública. Para relatar uma falha de segurança, use o contato:

`[EMAIL DE SEGURANCA]`

Ao reportar um problema:

- Não inclua senhas, tokens, cookies, dados pessoais, valores financeiros ou conteúdo privado.
- Não publique detalhes exploráveis em issues, pull requests ou discussões públicas.
- Não realize testes invasivos contra o ambiente de produção sem autorização explícita.
- Informe apenas o contexto necessário para reprodução responsável.

Relatos de segurança serão avaliados de forma privada pelo mantenedor.
